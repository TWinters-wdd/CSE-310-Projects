# Warrior Dash

Warrior Dash is a game made from the Python Arcade. The game features an animated sprite, sound, an unmovable object (the sun), and two collisions between different objects (player killing enemy, and the enemy hitting the player). Each enemy attacks from different sides of the player.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install VSCode
2. Download the python programming language/interpreter
3. Run the "python -m pip install arcade" command or "py -m pip install arcade" command
4. On the Game.py file, click the run button on the top right of the IDE

Instructions for using the software:

1. Run the program
2. Use W, A, and D keys to swing the sword as the enemies reach you
3. Last as long as you can!
